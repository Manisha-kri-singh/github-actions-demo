# 🚀 CI/CD Pipeline Using GitHub Actions

## 📌 Project Overview

This project demonstrates how to automate the deployment of a Dockerized web application to an AWS EC2 instance using GitHub Actions.

Whenever code is pushed to GitHub, the CI/CD pipeline automatically deploys the latest version to the EC2 server.

---

## 🛠 Technologies Used

- GitHub
- GitHub Actions
- Docker
- AWS EC2
- Nginx
- Linux (Ubuntu)
